# Grado de Matemáticas

Vault de Obsidian para el curso 2026-2027 de Álex.

Empieza en [[00 Inicio/Inicio|Inicio]]. El funcionamiento diario está explicado en [[00 Inicio/Manual de uso|Manual de uso]]. El sistema está diseñado para estudiar matemáticas con rigor, resolver muchos problemas y utilizar la IA como tutor, no como sustituto del razonamiento.

## Apertura en Obsidian

1. Descomprime el archivo.
2. En Obsidian, elige **Abrir carpeta como vault**.
3. Selecciona la carpeta `Grado_Matematicas`.
4. Abre [[00 Inicio/Inicio|Inicio]].

Los índices, colas de problemas y repasos espaciados se generan con Bases, la función nativa de bases de datos de Obsidian (requiere Obsidian 1.9 o superior). Incluye cuatro plugins comunitarios ya configurados — Latex Suite, Templater, Spaced Repetition y Excalidraw — descritos en [[00 Inicio/Plugins|Plugins]]. La carpeta de plantillas y las notas diarias ya están configuradas.
